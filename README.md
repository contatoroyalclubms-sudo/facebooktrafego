# Facebook Tráfego

Projeto para gerenciamento de tráfego do Facebook.

## Descrição

Este projeto foi criado para gerenciar e analisar o tráfego de campanhas do Facebook.

## Configuração

### Pré-requisitos

- Node.js (versão 18 ou superior)
- npm ou yarn

### Instalação

```bash
# Clone o repositório
git clone https://github.com/contatoroyalclubms-sudo/facebooktrafego.git

# Entre no diretório
cd facebooktrafego

# Instale as dependências
npm install
```

### Uso

```bash
# Inicie o servidor de desenvolvimento
npm run dev
```
